# MOTAIBI MOTION

مهارات Claude Code لعمل فيديوهات موشن جرافيك عربية قصيرة (9:16): من تثبيت الأدوات، إلى تعلّم ذوقك من الفيديوهات اللي بتعجبك، إلى المونتاج والتعديل.

| المهارة | شو بتعمل | عبارة التشغيل |
|---|---|---|
| `motion-setup` | تثبّت الأدوات الخمس وتجهّز مجلد المشروع | «ثبّت الأدوات» |
| `motion-taste` | تحلّل الفيديوهات المرجعية وتكتب دليل أسلوبك | «تعلّم ذوقي» |
| `motion-montage` | تفرّغ صوتك وتبني الفيديو وتصدّره MP4 | «منتج الفيديو» |
| `motion-revise` | تعدّل الجزء اللي بتطلبه بس | «غيّر هذا الجزء…» |

## التثبيت في Claude Code
```
/plugin marketplace add Abedelrahman97/motaibi-motion
/plugin install motaibi-motion@motaibi-motion-marketplace
```

## الأدوات المطلوبة
Node.js 22+ · FFmpeg · yt-dlp · Whisper (faster-whisper) · HyperFrames (من HeyGen، مفتوح المصدر)

## ملاحظة
الفيديوهات المرجعية للتعلّم من الأسلوب فقط. لا تستخدم لقطاتها أو موسيقاها أو شعاراتها في فيديوك.
